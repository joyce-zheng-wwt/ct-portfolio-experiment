# Design Intent — Variant 4: Technical / Data-Forward

---

## 01 — Emotional Arc

**The page feels like:**
```
A command line interface rendered as a website.
Technical, debug-like, with a sense of precision and control.
```

**By the CTA, the user feels:**
```
Compelled by technical capability and clarity.
```

---

## 02 — Motion Philosophy

**Easing:** `expo.out` (snappy, modern SaaS)

**Choreography:**
- Reveals: instant or fade-in (quick)
- Interactions: snap (no easing)
- Scroll: none (content-focused)

---

## 03 — Aesthetic Vocabulary

**Density:** Maximal (fill available space, content-packed)

**Typography tone:** Technical / mono (code-like, developer-focused)

**Color approach:** Monochromatic (dark bg) + neon accent (single pop color like cyan, lime, or magenta)

**Decoration:** Atmospheric (grids, nodes, data visualization elements)

---

## Design Specifics

- Dark background (#0A0E27 or similar)
- Monospace everywhere (even headlines)
- Neon accent color (#00FF00, #00FFFF, or #FF00FF)
- Grid overlays and geometric patterns
- Data visualization metaphor
- Code-like syntax highlighting
- Debug inspector aesthetic
- No rounded corners (all 0-4px)
- Terminal-like color palette
